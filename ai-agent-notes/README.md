## 全书最核心的 10 句话

1. **Agent = LLM + 上下文 + 工具**（大脑 + 眼睛 + 手脚），三者缺一不可。
2. **扩展眼睛和手脚是最主要的能力杠杆**——模型固定时，重新定义观察空间与动作空间常能把不可解任务变可解。
3. **上下文 = 静态前缀 + 轨迹**；静态前缀保持稳定（KV Cache），动态信息追加末尾。
4. **Harness 是竞争力所在**——模型商品化，差异在"约束、验证、纠正"。
5. **模型此刻的能力边界，就是 Harness 此刻的价值所在**（模型每内化一层，Harness 就卸下一层，转兜底新前沿）。
6. **SFT 记忆，RL 泛化**；**数据和环境比算法更重要**。
7. **多 Agent 的价值取决于是否引入新信息**（代码执行/视觉渲染/工具验证的外部反馈）。
8. **循环的瓶颈在验证器，不在模型**——由验证器判定"何时可以停"，而非模型自己。
9. **保存经历 ≠ 从经历中学习**——学习发生在"评价、对照、归纳、验证"之后。
10. **"看到什么、能做什么、如何验证做得对不对"这三个问题不会过时。**

## 全书贯穿的五个设计模式（心法）

1. **提议者—审核者（Proposer-Reviewer）**：产出与评判由两个不共享上下文的角色分别承担。
2. **渐进式披露（Progressive Disclosure）**：先给可检索目录，按需加载细节。
3. **只增不改（Append-only）**：状态追加演进，换来可缓存/可重放/可审计。
4. **边界集 + 保留集（Boundary Set + Retention Set）**：任何修改同时验证"应改变"和"不应影响"的样本。
5. **最小 diff + 可回滚**：每次修改尽量小、带来源、可单独回滚。

## 全书贯穿的安全骨架（三层护栏）

- **上下文层**：管模型能看到什么（来源标注、指令与数据分离、分类器）。
- **执行层**：管模型能做什么（工具风险评级、独立审查、最小权限、沙盒、Sidecar、人在回路）。
- **数据层**：管世界最终能被改成什么样（行级安全、约束校验、不可伪造的访问上下文）。
