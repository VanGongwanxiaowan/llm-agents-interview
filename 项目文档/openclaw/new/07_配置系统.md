# 07_配置系统

## 1. 配置系统概述

OpenClaw 使用**声明式配置**来管理整个系统：

```yaml
# openclaw.yaml
agents:
  my-agent:
    model: claude-sonnet-4-20250514
    provider: anthropic

channels:
  telegram:
    enabled: true

plugins:
  entries:
    web-search:
      enabled: true
```

**为什么用声明式配置？**
- 配置与代码分离，便于管理
- 支持版本控制（配置文件可以 git）
- 可以远程修改配置
- 启动时一次性加载所有依赖

## 3. 配置 Schema

### 3.1 Zod Schema 验证

```typescript
// src/config/zod-schema.ts
import { z } from "zod";

// Agent 配置 Schema
export const AgentConfigSchema = z.object({
  id: z.string(),
  model: z.string(),
  provider: z.string().optional(),
  systemPrompt: z.string().optional(),
  tools: z.array(z.string()).optional(),
  modelOverrikes: z.record(z.record(z.any())).optional(),
});

// Channel 配置 Schema
export const ChannelConfigSchema = z.object({
  enabled: z.boolean().default(true),
  botToken: z.string().optional(),
});
```

**为什么用 Zod？**
- 运行时类型检查
- 自动生成错误信息
- 支持默认值自动填充
- 可以生成 JSON Schema

## 4. 配置加载流程

```typescript
// src/config/io.ts
export async function loadConfig(): Promise<OpenClawConfig> {
  // 1. 确定配置文件路径
  const configPath = resolveConfigPath();

  // 2. 读取配置文件
  const fileContent = await readFile(configPath, "utf-8");

  // 3. 解析 YAML/JSON
  const parsed = parseConfig(fileContent);

  // 4. 应用环境变量覆盖
  const withEnv = applyEnvOverrides(parsed);

  // 5. 合并默认值
  const withDefaults = applyDefaults(withEnv);

  // 6. 验证 Schema
  const validated = validateConfig(withDefaults);

  return validated;
}
```

### 4.1 配置文件路径

```typescript
// 配置文件搜索顺序
```

### 4.2 环境变量覆盖

```typescript
// 环境变量命名规则
// OPENCLAW_AGENTS_{AGENT_ID}_MODEL
// TELEGRAM_BOT_TOKEN
// OPENAI_API_KEY

export function applyEnvOverrides(config: OpenClawConfig): OpenClawConfig {
  // 扫描所有环境变量
  for (const [key, value] of Object.entries(process.env)) {
    // 转换格式
    const override = parseEnvVar(key, value);
    if (override) {
      config = applyOverride(config, override);
    }
  }
  return config;
}
```

## 5. 配置验证

### 5.1 验证层级

```
┌─────────────────────────────────┐
│  Manifest 验证 (插件清单)        │  ← 最快，只读文件
├─────────────────────────────────┤
│  Config Schema 验证 (配置结构)    │
├─────────────────────────────────┤
│  Config Semantics 验证 (语义)     │
├─────────────────────────────────┤
│  Runtime 验证 (运行时检查)        │  ← 最慢，需要加载代码
└─────────────────────────────────┘
```

## 6. 配置热重载

### 6.1 文件监视

```typescript
// src/config/io.ts
export function watchConfigFile(
  path: string,
  callback: (newConfig: OpenClawConfig) => void
): void {
  // 使用 fs.watch 或 chokidar 监视文件变化
  fs.watch(path, async (eventType) => {
    if (eventType === "change") {
      const newConfig = await loadConfig();
      callback(newConfig);
    }
  });
}
```

### 6.2 重载传播

```typescript
// 配置变更时，通知各个子系统
registerConfigWriteListener(async (newConfig) => {
  // 1. 重新加载插件配置
  await reloadPlugins(newConfig.plugins);

  // 2. 重新加载渠道配置
  await reloadChannels(newConfig.channels);

  // 3. 重新加载 Agent 配置
  await reloadAgents(newConfig.agents);
});
```

## 8. 配置版本管理

### 8.1 配置快照

```typescript
// 每次写入配置前，保存快照
export async function snapshotConfig(config: OpenClawConfig): Promise<void> {
  const snapshotDir = path.join(stateDir, "config-snapshots");
  const timestamp = Date.now();
  const filename = `config-${timestamp}.yaml`;

  await fs.mkdir(snapshotDir, { recursive: true });
  await fs.writeFile(path.join(snapshotDir, filename), stringify(config));
}
```

### 8.2 配置回滚

```typescript
// 回滚到之前的配置
export async function rollbackConfig(version: string): Promise<void> {
  const snapshotPath = path.join(stateDir, "config-snapshots", `config-${version}.yaml`);
  const config = await loadConfigFromFile(snapshotPath);
  await saveConfig(config);
}
```

## 9. 配置示例

### 9.1 完整配置

```yaml
# openclaw.yaml

# 全局设置
gateway:
  host: "0.0.0.0"
  port: 18789

# 代理设置
proxy:
  enabled: true
  url: "http://proxy:8080"

# 模型配置
models:
  providers:
    anthropic:
      apiKey: ${ANTHROPIC_API_KEY}
    openai:
      apiKey: ${OPENAI_API_KEY}

# Agent 配置
agents:
  default:
    model: claude-sonnet-4-20250514
    provider: anthropic
    systemPrompt: |
      你是一个有用的 AI 助手。
    tools:
      - bash
      - read
      - write

# Channel 配置
channels:
  telegram:
    enabled: true
    botToken: ${TELEGRAM_BOT_TOKEN}

  discord:
    enabled: true
    botToken: ${DISCORD_BOT_TOKEN}

# 插件配置
plugins:
  entries:
    web-search:
      enabled: true
    memory:
      enabled: true

# 会话配置
sessions:
  retention:
    maxAge: 30d
    maxMessages: 1000

# 日志配置
logging:
  level: info
  file: ~/.openclaw/logs/gateway.log
```

## 12. 常见配置错误

| 错误 | 原因 | 解决方法 |
|------|------|----------|
| `Config not found` | 配置文件路径错误 | 检查 `openclaw.yaml` 是否存在 |
| `Invalid schema` | YAML 格式错误 | 检查 YAML 语法 |
| `Missing required field` | 缺少必填字段 | 添加缺失的配置 |
| `Invalid env var reference` | 环境变量不存在 | 设置对应的环境变量 |
| `Auth failed` | API key 错误 | 检查 API key 是否正确 |

## 13. 缺点与不足

| 缺点 | 说明 |
|------|------|
| **配置复杂** | 配置项非常多，学习成本高 |
| **缺乏校验** | 部分配置只有在运行时才校验 |
| **文档不足** | 配置项的含义不够清晰 |
| **覆盖优先级** | 多层覆盖机制复杂，难以调试 |
